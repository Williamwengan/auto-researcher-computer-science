# AAAI-27 Paper Scaffold

This is an anonymous draft scaffold. Before submission, download the official AAAI-27 Author Kit from https://aaai.org/authorkit27/ and place the official `aaai2027.sty` and bibliography style files here. The official page returned HTTP 403 to automated retrieval on 2026-07-14, so no unofficial or older style file is vendored.

Compile after installing the official kit:

```bash
latexmk -pdf main.tex
```

Do not add author names, affiliations, acknowledgements, repository owner names, local absolute paths, or identifying metadata to the review version.
